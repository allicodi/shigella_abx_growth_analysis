# Effects of *Shigella* Diarrhea on Linear Growth With and Without Antibiotic Treatment: A Meta-Analysis of Five Multisite Studies Among Children in Low-Resource Settings

This repository contains the code used to generate the results and figures for the manuscript:  
**"Effects of *Shigella* diarrhea on linear growth with and without antibiotic treatment: a meta-analysis of five multisite studies among children in low-resource settings."**

## System requirements

A working installation of R 4.5.2 is required. Package dependencies and their versions are recorded in `renv.lock` (see Installation).

Installing packages from source may require additional build tools:
- macOS: Xcode Command Line Tools and, for packages containing Fortran code, a compatible GNU Fortran compiler.
- Windows: Rtools compatible with the installed R version.
- Linux: compilers and system development libraries required by the packages being installed.

The analyses were run using R 4.5.2 on macOS 26.5.2 with an M3 processor.

## Installation

1. Install R 4.5.2, the version used for this project.
2. Clone or download this repository.
3. Start R from the repository's root directory. The included startup script will install and activate the project's version of `renv` if needed. An internet connection is required to download packages.
4. Restore the package library by running:

   ```r
   renv::restore()
   ```

   Confirm the installation when prompted. This installs the package versions recorded in `renv.lock` into a project-specific library.

5. Check that the library matches the lockfile:

   ```r
   renv::status()
   ```

If package installation requires compilation from source, install the build tools described above and rerun `renv::restore()`.

The analysis scripts rely extensively on the `abxGrowth` R package, which provides functions for data preprocessing, model fitting, and effect estimation.

Typical installation time can range from seconds to up to thirty minutes depending on download speeds and whether packages require compilation.

## Repository Structure

The repository is organized into four main folders:

### 1. `code/`
This folder contains all scripts used to prepare data, run analyses, and generate figures.  
- **`prep_data/`** – Scripts to create analysis-ready datasets from the raw data for each of the five studies and overall IPD analysis.  
  - Includes scripts for both *case-only/no-etiology comparison* and *case-control* versions of the analysis.  
  - Also includes code to combine study-level datasets into the overall individual participant data (IPD) dataset.  
  - Note- Running the original data preparation scripts requires access to the raw data from all five studies. 
- **`run_analyses/`** – Scripts to run all primary and supplementary analyses.
- **`create_figures/`** – Scripts to generate figures using the output produced by the `run_analyses` scripts.

### 2. `data/`
Contains subfolders for:
- Each of the five individual studies 
- The combined IPD datasets used in the meta-analysis
- **`sample_data/`** - Small simulated datasets for each study and the combined IPD analysis, including both case-only/no-etiology comparison and case-control versions.

The GitHub repository includes simulated datasets for demonstration purposes. The file paths throughout the code reference the original analysis datasets, which are not publicly available in this repository. Users can substitute the corresponding datasets in `sample_data/` to demonstrate the analysis workflow without access to the original data. These simulated datasets are intended for demonstration purposes only; any results generated from simulation data should not be interpreted.

See the Data Availability section of the manuscript for further information on accessing the original study data.

### 3. `results/`
Contains output generated by the analysis scripts in `code/run_analyses`.

### 4. `figures/`
Contains all figures produced by the scripts in `code/create_figures`.

## Demo run

### Data preparation

Running the data preparation scripts requires access to the original raw data from all five studies, which are not included in this repository. See the Data Availability section of the manuscript for information on accessing the original study data.

To prepare the analysis data from raw data, from the command line with working directory equal to the project's root directory, execute:

```bash
DATA_NAMES=(abcd efgh gems maled vida ipd)
for DATA_NAME in "${DATA_NAMES[@]}"; do
  Rscript "code/prep_data/prep_${DATA_NAME}.R"
done
```

Alternatively, the data preparation scripts can be run interactively to generate individual datasets of interest.

Data preparation time varies by study, ranging from a few seconds for simpler cleaning procedures (e.g., ABCD) to approximately 10 minutes per dataset and case definition for more complex processing (e.g., MAL-ED case-control). Some scripts generate multiple datasets using different case definitions, so total execution time will take longer.

### Model fitting and analysis

After data have been prepared, we can run the analytic code needed to produce results that are reported in the manuscript.

Each analysis is separated into a script with the naming convention `run_[analysis].R` with `[analysis]` replaced by a label describing the analysis. These can be run individually at the command line using: 

```bash
Rscript code/run_analyses/run_[analysis].R
```

Note some scripts contain several arguments that can be toggled for different analysis subgroups (e.g. `run_obs_abx_severity_stratified.R` contains options for age subgroups, severity subgroups)

A summary of what each analysis script does is included below:

- `run_case_control.R`:  Runs study-specific and pooled individual participant data (IPD) analyses comparing linear growth following *Shigella*-attributable diarrhea with controls. Used to create: __Figures: 1, 2, S2__.
- `run_no_etiology.R`: Runs study-specific and pooled IPD analyses comparing linear growth following *Shigella*-attributable diarrhea with diarrhea of no identified etiology. Used to create: __Figures 2, 3, S7, S8__.
- `run_monthly_growth_effects.R`: Runs longitudinal case-control analyses in MAL-ED to estimate growth differences at monthly intervals over 12 months following diarrhea, under observed antibiotic use, with options to restrict analyses by diarrhea severity. Used to create: __Figure 4__. 
- `run_abx_susceptibility.R`: Runs antibiotic susceptibility analyses in EFGH, examining controlled effects of *Shigella*-attributable diarrhea on HAZ when treated with an antibiotic the isolate was susceptible or non-susceptible to. Used to create: __Figure 5__.
- `run_obs_abx_severity_stratified.R`: Runs pooled IPD case-control analyses under observed antibiotic use, with options to restrict analyses by diarrhea severity and age group. Used to create: __Figures: S1, S3, S4__.
- `run_sens_effect_heterogeneity.R`: Runs pooled IPD analyses to check for effect heterogeneity by baseline HAZ and study. Used to create: __Figures: S5, S6, S9__
- `run_sens_loo.R`: Runs pooled leave-one-study-out analyses to check for effect heterogeneity by study. Used to create: __Figures: S6, S9__
- `run_sens_dysentery.R`: Runs analyses distinguishing *Shigella* diarrhea with and without dysentery, using both comparison groups and including study-specific, pooled IPD, and age-stratified estimates. Used to create: __Figures: S10, S11__.
- `run_subtype.R`: Runs pooled IPD analyses distinguishing *S. flexneri* and *S. sonnei*, using both the no-etiology and case-control comparisons. Used to create: __Figures: S12, S13__.
- `run_case_control_culture.R`: Repeats the case-control comparison using culture-attributable definition for *Shigella*. Used to create __Figure S14__.
- `run_no_etiology_culture.R`: Repeats the no-etiology comparison using culture-attributable definition for *Shigella*. Used to create: __Figure S15__. 
- `run_all_other_diarrhea.R`: Runs sensitivity analyses comparing *Shigella*-attributable diarrhea with all other diarrhea, using study-specific and pooled IPD data. Used to create __Figure S16__.
- `run_overlap_diagnostics.R`: Reruns primary IPD analyses retaining propensities needed to examine overlap diagnostics. Used to greate: __Figure S17__.
- `run_EED.R`: Runs analyses examining environmental enteropathy subclinical Shigella. Used to generate: __Figures: S18, S19, S20__.

`SL.wrappers.R` defines custom SuperLearner models and variable-screening functions used by the analysis scripts and is sourced automatically when needed.

Results are saved as R objects (`.Rds` files) in subdirectories of `results/` corresponding to each analysis. These files contain effect estimates and associated uncertainty measures and are used by the figure-generation scripts described below. When run on the simulated demo data, the numerical results will differ from those reported in the manuscript, and simulation data should not be used for conclusions.

Run time for the analysis scripts will vary across the scripts. The longest analyses are the ones where models are trained using the full IPD data (e.g., `run_no_etiology.R`). 
The IPD component of this scripts may take approximately 45 minutes to run, with individual studies taking less time.

### Visualizing results

After the analysis scripts have completed, run the corresponding scripts in `code/create_figures/` to generate the manuscript figures. Scripts are named by figure number in the main manuscript and analysis (e.g., `figure_1_case_control.R`), and outputs are saved to `figures/`.
