## Installation

1. Install R 4.5.2, the version used for this project.
2. Clone or download this repository.
3. Start R from the repository's root directory. The included startup script will install and activate the project's version of `renv` if needed. An internet connection is required to download packages.
4. Restore the package library by running:

   ```r
   renv::restore()
   ```

   Confirm the installation when prompted. This installs the package versions recorded in `renv.lock` into a project-specific library.

5. Check that the library matches the lockfile:

   ```r
   renv::status()
   ```

If package installation requires compilation from source, install the build tools described above and rerun `renv::restore()`.

## Repository Structure

The repository is organized into four main folders:

### 1. `code/`
This folder contains all scripts used to prepare data, run analyses, and generate figures.  
- **`prep_data/`** – Scripts to create analysis-ready datasets from the raw data for each of the five studies and overall IPD analysis.  
  - Includes scripts for both *case-only/no-etiology comparison* and *case-control* versions of the analysis.  
  - Also includes code to combine study-level datasets into the overall individual participant data (IPD) dataset.  
- **`run_analyses/`** – Scripts to run all primary and supplementary analyses.
- **`create_figures/`** – Scripts to generate figures using the output produced by the `run_analyses` scripts.

### 2. `data/`
Contains subfolders for:
- Each of the five individual studies 
- The combined IPD datasets used in the meta-analysis

### Model fitting and analysis

After data have been prepared, we can run the analytic code needed to produce results that are reported in the manuscript.

Each analysis is separated into a script with the naming convention `run_[analysis].R` with `[analysis]` replaced by a human readable label for the analysis. These can be run individually at the command line using: 

```bash
Rscript code/run_analyses/run_[analysis].R
```

A summary of what each analysis script does is included below: (**TODO: Allison verify**)

- `run_no_etiology.R`: Runs study-specific and pooled individual participant data (IPD) analyses comparing linear growth following *Shigella*-attributable diarrhea with diarrhea of no identified etiology, accounting for antibiotic treatment. Used to create: __Figures 1, 2, and S1__.
- `run_case_control.R`: Runs study-specific and pooled IPD analyses comparing linear growth following *Shigella*-attributable diarrhea with matched controls, accounting for antibiotic treatment. Used to create: __Figures: 2, 4, and S3__.
- `run_abx_susceptibility.R`: Runs EFGH analyses examining antibiotic susceptibility in relation to the association between *Shigella* diarrhea, antibiotic treatment, and subsequent linear growth. Used to create: __Figure 5__.
- `run_age_stratified.R`: Runs pooled IPD analyses separately for children aged 0–11, 12–23, and 24–59 months, using both the no-etiology and case-control comparisons. Used to create __Figures: S7 and S8__.
- `run_all_other_diarrhea.R`: Runs sensitivity analyses comparing *Shigella*-attributable diarrhea with all other diarrhea, using study-specific and pooled IPD data. Used to create __Figure S6__.
- `run_no_etiology_culture.R`: Repeats the no-etiology comparison using culture-based identification of *Shigella*. Used to create: __Figure S4__. 
- `run_case_control_culture.R`: Repeats the case-control comparison using culture-based identification of *Shigella*. Used to create __Figure S5__.
- `run_dysentery.R`: Runs analyses distinguishing *Shigella* diarrhea with and without dysentery, using both comparison groups and including study-specific, pooled IPD, and age-stratified estimates. Used to create: __Figure S10__.
- `run_monthly_growth_effects.R`: Runs longitudinal case-control analyses in MAL-ED to estimate growth differences at monthly intervals over 12 months following diarrhea, under observed antibiotic use, with options to restrict analyses by diarrhea severity. Used to create: __Figure 3__. 
- `run_severity_stratified.R`: Runs pooled IPD case-control analyses under observed antibiotic use, with options to include moderate-to-severe diarrhea, less-severe diarrhea, or both. Used to create: __Figure TODO: ???__.
- `run_obs_abx_severity_stratified.R`: Runs pooled IPD case-control analyses under observed antibiotic use, with options to restrict analyses by diarrhea severity and age group. Used to create: __Figures S2 and S9__.
- `run_subtype.R`: Runs pooled IPD analyses distinguishing *S. flexneri* and *S. sonnei*, using both the no-etiology and case-control comparisons. Used to create: __Figure S11__.

`SL.wrappers.R` defines custom SuperLearner models and variable-screening functions used by the analysis scripts and is sourced automatically when needed.

Results are saved as R objects (`.Rds` files) in subdirectories of `results/` corresponding to each analysis. These files contain effect estimates and associated uncertainty measures and are used by the figure-generation scripts described below. When run on the simulated demo data, the numerical results will differ from those reported in the manuscript.

Run time for the analysis scripts will vary across the scripts. The longest analyses are the ones where models are trained using the full IPD data (e.g., `run_no_etiology.R`).
