# Effects of *Shigella* Diarrhea on Linear Growth With and Without Antibiotic Treatment: A Meta-Analysis of Five Multisite Studies Among Children in Low-Resource Settings

This repository contains the code used to generate the results and figures for the manuscript:  
**"Effects of *Shigella* diarrhea on linear growth with and without antibiotic treatment: a meta-analysis of five multisite studies among children in low-resource settings."**

## Repository Structure

The repository is organized into four main folders:

### 1. `code/`
This folder contains all scripts used to prepare data, run analyses, and generate figures.  
- **`prep_data/`** – Scripts to create analysis-ready datasets from the raw data for each of the five studies and overall IPD analysis.  
  - Includes scripts for both *case-only/no-etiology comparison* and *case-control* versions of the analysis.  
  - Also includes code to combine study-level datasets into the overall individual participant data (IPD) dataset.  
- **`run_analyses/`** – Scripts to run all primary and supplementary analyses.
- **`create_figures/`** – Scripts to generate figures using the output produced by the `run_analyses` scripts.

### 2. `data/`
Contains subfolders for:
- Each of the five individual studies 
- The combined IPD datasets used in the meta-analysis

### 3. `results/`
Contains output generated by the analysis scripts in `code/run_analyses`.

### 4. `figures/`
Contains all figures produced by the scripts in `code/create_figures`.
